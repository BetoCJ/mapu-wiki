# 💬 Juegos del chat (MapuJuegos)

_Actualizado el 23/11/2026._

Cada cierto tiempo aparece en el chat (y en pantalla) un **mini-juego rápido**: el primero que escribe la respuesta correcta gana dinero, experiencia y a veces premios extra.

***

## ⚙️ Cómo funciona

| | |
|---|---|
| **Frecuencia** | Un juego cada **10 minutos** |
| **Jugadores necesarios** | Al menos 3 conectados |
| **Tiempo para responder** | 25 segundos |
| **Cómo responder** | Escribe la respuesta en el chat normal |

* Las respuestas **no distinguen mayúsculas ni tildes**: las palabras van sin tildes ni ñ para que se puedan escribir rápido, incluso desde el celular.
* Gana solo el **primero** en responder bien.
* Si estás **silenciado** no puedes ganar, y tampoco cuenta lo que escribas mientras respondes a otro menú del servidor.
* Tu **racha** de victorias seguidas queda guardada aunque el servidor se reinicie.

***

## 🎲 Los juegos

| Juego | Qué tienes que hacer | Premio fijo |
|---|---|---|
| **Copiar rápido** | Copiar la palabra que aparece | $150 + 80 XP |
| **Ordena las letras** | Ordenar las letras desordenadas de una palabra | $200 + 100 XP |
| **Al derecho** | Escribir al derecho una palabra que aparece al revés | $200 + 100 XP |
| **Completa la palabra** | Completar las letras que faltan | $200 + 100 XP |
| **Copia el código** | Copiar un código de letras y números | $250 + 120 XP |
| **Matemáticas** | Resolver una operación (+, − y ×) | $300 + 150 XP |
| **Serie numérica** | Adivinar el número que sigue en la serie | $300 + 150 XP |
| **Cuenta** | Contar cuántas veces aparece un símbolo | $300 + 150 XP |
| **Adivina el valor** | Calcular el valor de un símbolo | $350 + 170 XP |
| **Trivia** | Responder una pregunta de Minecraft | $400 + 200 XP |

Además del premio fijo, cada victoria puede dar **extras al azar**: más dinero, 16 frascos de experiencia, MapuPoints o una llave (Llave Diaria, o Llave Piñata en Trivia y Adivina el valor). Las palabras son del servidor y del mundo mapuche: Wallmapu, Kultrun, Weichafe, Araucaria, Copihue y muchas más.

***

## 📜 Comandos

| Comando | Qué hace |
|---|---|
| `/chatgames top` | Ranking de ganadores (alias `/mapujuegos`) |
| `/chatgames stats` | Tus estadísticas |
| `/chatgames toggle` | Activar o desactivar los juegos para ti |
| `/chatgames help` | Ayuda |
