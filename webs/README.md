## 📋 Resumen

| Web | Para qué sirve | Dirección |
|---|---|---|
| 🏘️ **Portal del servidor** | Estado del servidor, ciudades, naciones, jugadores, rankings, mapa en vivo, mercado, calendario de eventos, mascotas en 3D y soporte | [servidor.mapucraft.com](https://servidor.mapucraft.com) |
| 🛒 **Tienda** | Rangos, llaves, MapuPoints, Pase de Batalla, claims, spawners y más. Incluye la página para votar | [mapucraft.com](https://mapucraft.com) |
| ⚖️ **Sanciones** | Consultar baneos, silencios y advertencias, y apelar una sanción | [castigos.mapucraft.com](https://castigos.mapucraft.com) |
| 📖 **Wiki** | Esta guía con todos los sistemas del servidor | [mapu-1.gitbook.io/mapucraft](https://mapu-1.gitbook.io/mapucraft) |
| 💬 **Discord** | Comunidad, soporte del staff, eventos y avisos | [discord.gg/YDJKpgEU3m](https://discord.gg/YDJKpgEU3m) |

## 🔎 Casos típicos

| Quiero... | Voy a... |
|---|---|
| Saber si el servidor está en línea | [servidor.mapucraft.com/estado](https://servidor.mapucraft.com/estado) |
| Ver el mapa con las ciudades | [servidor.mapucraft.com/mapa](https://servidor.mapucraft.com/mapa) |
| Buscar mis horas jugadas y estadísticas | [servidor.mapucraft.com/jugadores](https://servidor.mapucraft.com/jugadores) |
| Ver los precios del mercado | [servidor.mapucraft.com/mercado](https://servidor.mapucraft.com/mercado) |
| Ver las mascotas girando en 3D | [servidor.mapucraft.com/mascotas](https://servidor.mapucraft.com/mascotas) |
| Comprar un rango o llaves | [mapucraft.com](https://mapucraft.com) |
| Votar y ganar recompensas | La página de votos de la [tienda](tienda.md) |
| Pedir ayuda al staff | [servidor.mapucraft.com/soporte](https://servidor.mapucraft.com/soporte) |
| Apelar un baneo | [castigos.mapucraft.com/protest](https://castigos.mapucraft.com/protest) |
| Revisar el estado de mi caso | [servidor.mapucraft.com/caso](https://servidor.mapucraft.com/caso) |
