# 🧭 Warps

_Actualizado el 23/11/2026._

Los **warps** te llevan al instante a los lugares importantes del servidor. Viaja con `/warp <nombre>` o abre el menú con **`/warps`**, que tiene dos páginas. Esta es la lista real de warps del menú.

{% hint style="info" %}
Los nombres respetan mayúsculas y tildes tal como aparecen aquí (por ejemplo `/warp Estadio`, `/warp FallGuy` o `/warp piñata`).
{% endhint %}

***

## ⚔️ Página 1 — Combate, Juegos y Eventos

| Warp | Lugar | Para qué sirve |
|---|---|---|
| `/warp coliseo` | Coliseo | Arena PvP |
| `/warp Estadio` | Estadio | Arena competitiva (aquí los amuletos se desactivan) |
| `/warp sumo` | Sumo | Duelos de sumo y apuestas → [Sumo](../towny/sumo.md) |
| `/warp preduels` | Pre-Duels | Sala de espera para los duelos (`/duel`) |
| `/warp koth` | KOTH | Rey de la Colina, cada 4 horas → [KOTH](../towny/eventos/koth.md) |
| `/warp dungeons` | Dungeons | Entrada a las mazmorras → [Dungeons](../towny/dungeons/README.md) |
| `/warp parkour` | Parkour | El parkour grande de saltos → [Mini-juegos](../towny/minijuegos.md) |
| `/warp FallGuy` | Fall Guys | Carrera de obstáculos |
| `/warp tntrun` | TNT Run | Minijuego de supervivencia |
| `/warp spleef` | Spleef | Minijuego de arena |
| `/warp PropHunt` | PropHunt | Escondite de objetos |
| `/warp evento` | Eventos | Sala de eventos |

## ❓ Preguntas frecuentes

**¿Existe `/warp comercio`, `/warp mercado` o `/warp predungeon`?**
No. Para comprar y vender usa `/ah` (casa de subastas), `/market` (mercado) o las tiendas de jugadores. A las dungeons se entra con `/warp dungeons`.

**¿Y los parkours cortos?**
No son un warp: se entra con `/mpk lobby`. → [Parkours cortos](../towny/parkours.md)

**¿Cómo vuelvo a mi town?**
Con `/t spawn` (y a tu nación con `/n spawn`).
